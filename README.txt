# Shanu's Hair Style — Free Booking Website Prototype

This package contains a mobile-friendly booking website prototype for:
- Shanu's Hair Style
- Hugam Siri Gufwara
- 9:00 AM – 5:00 PM
- Tuesday closed
- Haircut ₹50
- Beard ₹30
- Haircut + Beard ₹80
- 30-minute slots
- One customer per slot

## Important
This first version stores bookings in the browser's localStorage. That means it is a working prototype, NOT yet a real shared online booking database.

For the real version, the next step is to connect the booking form to a free cloud backend/database so:
- Customer A books 10:00 AM
- Customer B immediately sees 10:00 AM as Booked on another phone
- Shanu can view/cancel bookings from anywhere

## Files
- index.html = customer booking page
- admin.html = basic admin page
- style.css = design
- script.js = booking logic

## Quick test
Open index.html in a browser. Select a service, date and slot, then book. Open admin.html to see the booking on the same browser/device.

## Next step
